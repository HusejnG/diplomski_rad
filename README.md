Ovaj projekat je web aplikacija razvijena pomoću Laravel frameworka, dizajnirana da olakša proces kreiranja zahtjeva za ponudu solarnih sistema, upravljanje tim ponudama i procjenu potencijalne proizvodnje energije pomoću PVGIS API-ja. Aplikacija podržava različite korisničke uloge (kupac, dizajner, administrator) sa specifičnim dozvolama za svaku ulogu.
Tehnologije
Backend: Laravel (PHP Framework)
Baza podataka: MySQL 
Frontend: Blade templating engin, Bootstrap 5 (CSS Framework), JavaScript (za interaktivne elemente i PVGIS API pozive), Eksterni API: PVGIS (Photovoltaic Geographical Information System) API v5.2
Pokretanje Laravel razvojnog servera: php artisan serve
Pokretanje Vite razvojnog servera: npm run dev
